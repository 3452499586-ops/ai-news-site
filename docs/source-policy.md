# 信源规范

<a id="source-tiers"></a>
## 信源分级（source-tiers）

### 一级：原始官方资料

优先使用机构官网新闻、官方技术文档、更新日志、正式代码仓库、政府文件、标准机构文件、论文原文和会议正式页面。来源链接应直接指向能够证明该项事实的页面，而不是搜索结果或二次转载。

一级来源可以证明“该机构确实这样发布或声明”，但厂商自报跑分、用户数、效果比例和未来计划仍只能标为“官方声明”，不能自动视为独立事实。

### 二级：独立权威来源

Reuters、AP、Financial Times、Bloomberg、Nature、Science、MIT Technology Review 等具备公开编辑规范的媒体，可用于交叉核验商业、监管、人事、安全事故和争议事件。二级来源不能替代模型卡、技术文档或论文原文。

两个来源只有在编辑、数据采集和事实确认链路彼此独立时才算“双源”。同一新闻稿的两个转载站不算两个来源。

### 三级：线索来源

知乎、微博、微信公众号以及其他社交平台原则上仅用于发现线索。只有账号身份明确、日期清晰、内容可追溯到机构官网或正式文件时，才可作为补充来源。社交平台截图不得成为唯一证据。

## 科研与标准资料

使用 arXiv 时必须标注“预印本、尚未同行评审”；使用会议论文时注明接收或发表状态。不得把“上传到 arXiv”写成“获得学术界认可”。政府与标准信息应链接到发布机关的正式页面，并区分草案、征求意见稿和已生效文件。

<a id="forbidden-sources"></a>
## 禁止来源（forbidden-sources）

- 无原始链接的转载、聚合页或截图。
- 匿名爆料、群聊转发、无法确认身份的自媒体。
- 将广告文案、排行榜或点赞量当作事实依据的页面。
- 无法访问、已删除且没有可靠存档的唯一来源。
- 内容农场、自动改写站和未披露来源的摘要站。
- 需要突破访问控制、登录限制或付费墙才能核验的材料，不得作为普通读者唯一可查证的证据。

## 链接保存规则

每个 `sources` 项必须包含名称、类型、渠道和完整 HTTPS 地址。页面不会自动打开或预取这些链接；访问行为只能由用户主动触发。更新时应逐一确认链接仍能访问、标题与正文相符、发布日期未被误读，并记录原文是否修改或撤回。
